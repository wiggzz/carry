# AGENTS.md

- Use Conventional Commits for every commit.
- Before making a test pass, run it and confirm it fails for the intended missing behavior—not a setup, syntax, or unrelated failure.
- Keep pull-request descriptions concise: start with **why**, then describe only the high-level **what** needed to explain the motivation for each substantial change. Do not include mechanical file/change lists. Include only manual verification that CI will not run automatically.
